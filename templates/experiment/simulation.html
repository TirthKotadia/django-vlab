6

Key Concepts

Review the main ideas from this experiment.

1. STATIC_URL

Defines the URL prefix used to reference static resources, such as /static/.

2. STATICFILES_DIRS

Specifies additional directories in which Django looks for static files during development.

3. The static template tag

The static tag builds a resource URL using the configured static URL prefix and the specified file path.

4. HTTP status codes

A status such as 200 generally indicates success, while 404 means that the requested resource was not found at the requested URL.

5. Development and production

Django's development static-file serving differs from production deployment, where static resources are commonly collected and served by a web server or dedicated static-file service.
