Procedure

Follow these steps to serve static files in Django. The same steps are interactive in Simulation.

  1. Create static folders — Inside project root, create static/css/, static/js/, static/images/ and place your files there, e.g., static/css/style.css.
    project/ ├── manage.py ├── static/ │ ├── css/style.css │ └── images/logo.png
  2. Configure settings.py — Add at the bottom of settings.py:
    STATIC_URL = '/static/'
    STATICFILES_DIRS = [BASE_DIR / 'static'] — Try this in Simulation → Step 1
  3. Load static in template — At the very top of your HTML template, add:
    {% templatetag openblock %} load static {% templatetag closeblock %}
    <link rel="stylesheet" href="{% templatetag openblock %} static 'css/style.css' {% templatetag closeblock %}">
  4. Run and Verify — Run python manage.py runserver and open http://127.0.0.1:8000/. If configured correctly, CSS will apply and images will load (HTTP 200). If not, console shows 404. For production, run collectstatic.
